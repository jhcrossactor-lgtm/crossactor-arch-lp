## これまでに決まったこと

- 主役は「建築PV・パース・図面制作」。見せる相手は、パートナー（広告代理店・設計事務所）、工務店・不動産会社、地域の中小企業。
- 以前の LP（このリポジトリ）を土台にする。候補は2つで、呼び名は「青」と「黄色」。
  - **青**：`top-new.html` を暗いタンザナイト（ほぼ黒の濃紺に、青紫と紫の光を少し）にしたもの。
  - **黄色**：`index.html` を黄色地にして、トップを「物件資料 → 区割り → 建物 → 街並み」の動きにしたもの。
- 本人の好みは、フランクな **黄色**。
- 「IT・AIの中で設計している」雰囲気にしたい。ただし機械の中そのものにはしない。
- 見せ方は「図面から街ができる」ではなく **「物件資料だけでいい」**。
- **スクロールで絵が動く演出は入れない**（自動再生とクリック操作はよい）。
- 元のポートフォリオ（3D VR のページ）の、ロゴ・似顔絵・プロフィール文・資格一覧・3D VR の2本・制作過程は、そのまま使う。

## いま残っている一番の課題

黄色の試作は、**漫画・アニメっぽく見えてしまう**。本人が実際に作っているのは、かなりリアルな PV・パース。
**そのリアルさをトップに出しつつ、黄色をどう組み合わせるか**を解くのが次の仕事。

チャットで出した考え方（未決定）：

- 軸は「リアルな映像・画像が主役。黄色は枠・ラベル・線の役で、画面の1〜2割」。
- 組み方は3つ。
  1. **ファインダー型**：全面にリアルな PV を流し、その上に黄色でファインダーの印（四隅のかぎ括弧、タイムコード、「CUT 01」「No.3 203㎡」などの札）を重ねる。
  2. **分割型**：左半分は黄色の地に見出し、右半分は端までリアルな PV。境目で、物件資料の線画が完成のリアルな画面に変わっていく（自動で動く。スクロール連動にはしない）。
  3. **マーカー型**：白か薄いグレーの地に写真を大きく。黄色は下線・ボタン・ラベルだけ。
- おすすめとして出したのは、**トップは2（分割型）、作例一覧は1（ファインダー型）**。
- 漫画っぽさを抜くための具体策：
  - 太い黒線と、ずらした影（box-shadow 5px 5px 0）をやめる。残すのはボタンくらい。
  - ポップな書体（Dela Gothic One、Mochiy Pop One）をやめ、締まった太いゴシックにする。数字と札は等幅書体のまま。
  - 似顔絵はトップから外し、制作担当の欄へ。
  - 黄色を、パステル寄りの #FFD93B から、工事現場・測量の標識のような濃い黄色（#FFC400 あたり）へ。
  - 線画は主役にせず、リアルな映像の上に重ねる「読み取り・区割りの印」にする。

**必要なもの**：本人のリアルな作例（レンダリング画像2〜3枚、または PV の動画1本。街並み PV やウォークスルーなど）。載せるのは、物件名を変えて作り直した作例にする方針。

※ このリポジトリは公開なので、実際の物件名・取引先名はここに書かない。

## ファイルの役割

### 黄色（`index.html`）
| ファイル | 中身 |
|---|---|
| `kiiro.css` | 黄色地への色替え（上書き）。ナビは黒、ボタンは丸。 |
| `town.css` | トップの3案の切り替え、AIログ窓、再生バー、スマホの縦並び。和文フォントの読み込みもここ。 |
| `town.js` | トップの動き（Canvas 2D、ライブラリ無し、18秒で繰り返し）。物件資料の紙 → スキャン → 区割り（点と線のネットワーク）→ 家が立ち上がる（GEN タグ）→ 木と車 → CUT 01 の枠。AIの部分だけ紫（#4B2BD6）。 |
| `town-ui.js` | 再生バー（01 物件資料〜04 街並み、押すとその場面へ）、AIログの打ち出し、試作用の案の切り替え。 |
| `styles.css` / `sections.css` | 元の色の数値を黄色用に置き換えたもの。 |
| `hero3d.js` | 元の線画3Dの色を黒系に。今のトップでは使っていない（canvas の id を変えたため起動しない）。 |
| `assets/fonts-jp/` | Dela Gothic One・Zen Maru Gothic・Mochiy Pop One・Zen Kaku Gothic New（いずれも SIL OFL 1.1、ライセンス同梱）。 |
| `assets/egao.png` | 似顔絵（元のポートフォリオから）。 |

トップの3案：`index.html?v=1`（ステージ）・`?v=2`（モニター）・`?v=3`（大見出し）。
`&t=8` のように秒数を付けると、その場面で止まる（画面確認用）。右上か左上の黒い帯で切り替えもできる（試作だけの表示）。
